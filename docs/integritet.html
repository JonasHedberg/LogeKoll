LogeKoll version 1.0

Integritetspolicy

Senast uppdaterad den 9 augusti 2026. Den här policyn beskriver hur LogeKoll behandlar uppgifter i version 1.0.

Sammanfattning

LogeKoll kräver inget konto, innehåller inga annonser och använder inga analys- eller spårnings-SDK:er. Inställningar, sparade mötesreferenser, databas-cache, positionscache för offentliga institutionsadresser och Mina anteckningar lagras lokalt. Din aktuella position används bara när du själv startar en närhetssökning.

Integritetspolicyn finns även inne i appen via info-knappen i Inställningar.

1. Ansvarig och kontakt

LogeKoll tillhandahålls av apputvecklaren. Frågor om appen eller integritet kan lämnas via supportsidan. Offentliga supportärenden ska inte innehålla känsliga personuppgifter.

2. Uppgifter som lagras lokalt

Appen kan lagra vald medlemstyp, Min Loge, Mitt Läger, vald sökvisning, inställningar för röst-/genvägssökning och databassynkning, tidpunkt för senaste automatiska synkning, sparade mötesreferenser, lokal databascache och koordinater för offentliga institutionsadresser. Appens egna filer skrivs med enhetens tillgängliga filskydd.

3. Mina anteckningar

Mina anteckningar lagras som krypterad data endast på enheten. Krypteringsnyckeln sparas i systemets säkra nyckellagring och kräver enhetens ägarautentisering för åtkomst. Anteckningstexten skickas inte till LogeKolls databas eller supporttjänst.

4. Plats

Aktuell position begärs endast när du aktivt använder en nära-mig-funktion. Positionen används i minnet för att beräkna avstånd till institutioner och möten och skrivs inte till LogeKolls databas eller inställningar. Behörigheten kan nekas eller återkallas i enhetens systeminställningar.

5. Kartor och geokodning

För att beräkna avstånd kan offentliga institutionsadresser skickas till enhetens systemtjänst för kartor och geokodning. Resultatet kan sparas lokalt som koordinater tillsammans med ett tekniskt adressfingeravtryck. När du öppnar en adress lämnas den till enhetens kartfunktion.

6. Kalender

När du väljer att lägga till ett möte förbereder LogeKoll titel, institution, plats, tid och tillgängliga mötesanteckningar i systemets kalenderredigerare. Du avgör själv om posten sparas. LogeKoll läser inte din kalender och driver ingen egen kalenderserver.

7. Röstassistent och genvägar

Om funktionen aktiveras kan systemets röstassistent och genvägar söka institutioner och kommande möten. LogeKoll använder sin databas för sökningen och skickar inte dina lokala medlemsinställningar till LogeKolls databasserver. Systemleverantören kan behandla röst- och genvägsdata enligt enhetens egna villkor.

8. Databashämtning och nätverk

LogeKoll hämtar en databas. HTTP-cacheinformation används för att minska onödiga nedladdningar. Vid vanliga nätverksanrop kan tekniska anslutningsuppgifter, exempelvis IP-adress och tidpunkt, behandlas av nätverket och den server som levererar filen. Medlemstyp, heminstitutioner, sparade möten, privata anteckningar och aktuell position läggs inte till i denna databasförfrågan.

9. Telefon, e-post och externa länkar

När du väljer telefon, e-post, adress eller en källänk lämnar appen den valda uppgiften till enhetens motsvarande systemfunktion eller externa tjänst. Den fortsatta behandlingen sker enligt den tjänstens villkor.

10. Delning, annonser och spårning

Appen innehåller enligt version 1.0 inga tredjepartsannonser, analys-SDK:er eller funktioner som spårar användaren mellan appar och webbplatser. LogeKoll säljer inte lokala inställningar, sparade möten, platsdata eller privata anteckningar.

11. Radering

Min Loge, Mitt Läger och sparade möten kan tas bort i appen. Lokala appdata, inklusive krypterade anteckningar och cache, kan tas bort genom att radera appens lokala data från enheten. Anteckningsnyckeln är knuten till enhetens säkra lagring.

12. Ändringar

Policyn uppdateras när appens funktioner eller databehandling förändras. Den aktuella versionen publiceras på denna sida.
